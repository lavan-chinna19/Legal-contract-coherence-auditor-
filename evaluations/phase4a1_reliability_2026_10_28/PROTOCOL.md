# Phase 4A.1 focused reliability protocol

Scope is restricted to passive voice, joint/compound responsible parties, and event type versus
instance identity. No new model, action ontology, general coreference, contradiction detector or
new research phase. Existing core neural/structural/reference/temporal outputs must remain exact.

The byte-identical original Phase 4A binding module is retained in baseline_snapshot and checked
against its original frozen manifest. Run it again rather than treating an ablation as the baseline.
Original labels/predictions/reports stay unchanged. The former reserved examples are now exposed
development evidence. Additional focused examples are authored and hashed before repairs/final
testing; they are also authored development evidence, never unseen independent legal evaluation.

Original binary n16 = 8 labelled matches + 8 labelled differences; the passive positive abstains
and counts FN. Original decided subset n15 = 7 matches + 8 differences. Coverage15/30 is the
decided count divided by all 30 documents, including 12 uncertain, one unsupported-action and
one provisional example in addition to the 16 binary-labelled examples. One selected pair per
document is the original metric unit; all emitted pair workload is reported separately.

Recurrence field corrections are a separate explicit annotation overlay: four original cells
(left/right in each split) have no established occurrence, rather than a copied named invoice
type. Preserve both the original raw field metrics and the corrected-overlay counts; do not
change pair labels or use these exposed corrections as a validation claim.

Structured actors preserve all explicitly conjunctive responsible parties and a responsibility
mode; alternative or unknown subjects abstain. A supported passive requires an explicit by-agent;
no missing actor is supplied. Active/passive notification examples can establish equal actor/action/
recipient relationships without establishing the same notification occurrence. Pair MATCHED still
requires an explicit event instance and other relevant fields; type equality alone is insufficient.

Use a fixed small set of the same three substantive cached SEC contracts as Phase 4A, retaining
manifest URLs/identities/raw hashes and exact original extraction evidence. Raw markup stays
unsupported. Normalized views identify their own Unicode coordinate space, not HTML byte/page
coordinates. Report descriptive record/pair/document counts and abstention categories; no legal
or contradiction gold exists. Inspect at most three source-backed candidate pairs per document.

Four decision states are unchanged. Binary MATCHED screen uses all trustworthy binary labels:
abstention on a positive is FN; on a negative it is screen TN, not validated difference. Unknown
pair labels have no confusion score. Report all-case/document and all-emitted-pair coverage,
abstention, parser failures, unsupported grammar, ambiguous meaning and known bugs separately.
Only calculate P/R/F1 on mechanically defined synthetic labels. No synthetic score is legal accuracy.

Run one baseline/new focused comparison, affected integration and full native regression; fix
encountered bugs only within the three repairs and rerun affected checks. No indefinite benchmark
expansion. Docker runtime conditional on host engine. Finish with a documented GO/NO-GO, not Phase4B.
